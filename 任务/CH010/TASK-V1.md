- 章节：CH010《先把自己修回来》
- 阶段属性：第一阶段CH001—CH010正式收束章，同时是十章阶段审核关口。
- 模式：写手A/B/C三稿独立并行竞争。
- 字数：8000—10000，建议8500—9500。
- 前序真源：CH008、CH009正式LOCK与全部正式记忆。

## 二、必须承接的正式状态
1. CH009安澜宾馆第三工单已于04:04完成有限兼容修复。
2. 周砚身份稳定度仍12%，最高权限P1，无P2。
3. 顾显/白箱处已正式进入主线。顾显与周砚是专业互相观察＋有限合作＋未来方法论冲突，不是导师、好友或私人敌人。
4. 沈闻溪已经是稳定职业搭档，但仍无恋爱确认。
5. 安澜417深层根因仍未解：长期生成原因、历史正式房号、夜值第二把钥匙、4F西端辅助支路用途继续留长期伏笔。
6. 417案不能重新成为CH010主案件。

## 三、CH010必须完成的六个任务
### 1. 真正收束周砚第一阶段人物弧
不能靠旁白总结“他成长了”。必须让他主动接下、处理或推进一个与自身存在、父亲即时线索无直接利益关系的现实小故障，而且懂得让真正责任方共同验证和承担结果。

### 2. 沈闻溪稳定为长期职业搭档
她必须独立承担至少一个关键判断或验证，不是只提醒周砚“不能这样做”。两人应自然形成分工默契，但不正式恋爱确认，不靠旁人起哄。

### 3. 用行动固化第一阶段方法论
本章禁止重新开“事实权／运行权／恢复范围”概念说明会。通过具体事件体现：
- P1只提示哪里有差异，不给答案；
- 有标记不等于旧版本真，无标记不等于现版本真；
- 现实证据、记忆和因果仍由人核验；
- 恢复真实发生过的事实，不等于恢复旧形态或创造今天不存在的权利；
- 现实责任必须由真正承担责任的人共同闭环。

### 4. 再次出现轻度遗忘负荷
必须出现一次新的、可观察、短暂、可由现实证据纠正的遗忘压力。
可采用但不限于：
- 熟悉同事短暂把周砚刚完成的普通维修记成别人；
- 工作群/值班交接中短暂缺失或错记周砚的一项刚发生记录；
- 熟人把一段近期共同经历说错，但能被工单、照片、排班或聊天记录纠正。

禁止：
- 赵岚永久忘记周砚；
- 唐建国长时间不认识周砚；
- 周砚大面积社会身份消失；
- 直接升级为中期级严重遗忘伤害。

本章目的只是提醒读者：修复仍然有代价。

### 5. 周成／第七工位只推进极小一步
允许出现一个非常有限的新关联，例如：
- 白箱处公开级或边缘历史风险索引里出现“七号工位”旧字段；
- 某条2008风险记录里出现与七号工位相邻的不完整编号；
- 顾显只确认“七号工位”属于一个旧风险对象，但自己也不知道完整含义。

必须同时保护：
- 不揭周成完整身份；
- 不揭周成下落；
- 不解释七号工位制度；
- 不解释7·17空白夜全貌；
- 不解释城维协议；
- 不解释终端来源；
- 周成不正式现身。

更重要：周砚看到父亲线钩子后，必须能主动克制，不为了父亲抛下眼前普通人的现实问题。这是第一阶段人物弧的重要证明。

### 6. 自然打开CH011“被删掉的街区”
章末必须出现一个具体、可感知的城市地址异常入口。优先形式：
- 一张物业/市政维修单有真实地址和现实住户，但导航/配送/另一套地址系统拒绝该街段存在；
- 一位普通人明明居住、缴费、收件，却在某些系统里开始失去地址；
- 维修人员能到现场，却无法在部分系统创建、派发或关闭工单。

必须从“一张单、一个地址、一个普通人的损失”进入，不能突然切成城市级阴谋说明会。

## 四、顾显／白箱处本章用法
顾显可以出现，也可以只通过消息/有限协作出现，但必须继续保持：
- 有用；
- 有现实风险逻辑；
- 不全知；
- 不抢主角所有判断；
- 不把周砚收编成学生；
- 与周砚在某个具体选择上可以出现轻微方法分歧。

S-001延续护栏：若沈闻溪再次判断某机构/岗位异常，必须给自然可追溯来源，例如公开协作名单、项目通讯录、既往业务或她实际查过的目录。

## 七、推荐场景结构
1. CH009结束后的正常工作/生活落地，表现人物需要睡觉、交接、吃饭、继续本职。
2. 一个很小的普通维修差异事件，周砚主动处理，沈闻溪参与关键验证。
3. 轻度遗忘负荷出现并被现实记录纠正。
4. 顾显或白箱边缘信息带来“七号工位”极小新关联。
5. 周砚主动选择先解决普通人的现实损失，而不是立刻追父亲线。
6. 当前小事件闭合或达到清晰可控状态。
7. 章末新维修单/地址异常落下，打开CH011“被删掉的街区”。
