# xiaoshuo3 小说聊天工作流

100章，每章8000—10000字。七个普通Chat对话；各角色把自己的文件写到本仓库，你只复制回答末尾交接块。

首次打开 [系统/开场指令.txt](系统/开场指令.txt)，把七段短指令分别发给七个普通聊天对话。
随后把灵感原话发给灵感员；按每条回答末尾的“下一步复制给谁”继续。

首章：灵感员 → 总监 → 写手A → 写手B → 写手C → 裁判员 → 综合审核员 → 总监。
以后：总监 → 获选主写手 → 综合审核员 → 总监。需要返修就循环同章；通过并核验保存后，总监发下一章。

固定入口：[数据库入口.json](数据库入口.json)。执行状态：[运行状态.json](运行状态.json)。人类摘要：[当前进度.md](当前进度.md)。
角色指令：[系统/角色指令](系统/角色指令)。审核标准：[系统/综合审核标准.md](系统/综合审核标准.md)。

系统已配置不代表小说已立项。每个聊天的GitHub读写与计数能力须实际验证。
流程分工不等于技术权限隔离；聊天模式仍可能限额。本系统不承诺无漏洞、无限额度或文本一定被认作纯人工。
